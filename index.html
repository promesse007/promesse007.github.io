Comment fonctionne le livre d'or
Un site composé uniquement de fichiers HTML/CSS/JS ne peut pas enregistrer de message sur Internet : il a besoin d'un service de réception. La formule ci-dessus est prête à être branchée sur Formspree (formspree.io) : vous créez un compte, vous récupérez votre adresse de formulaire, puis vous remplacez VOTRE-ID-FORMSPREE par celle-ci dans galerie.js (ligne formspree). Tant que cette étape n'est pas faite, le formulaire l'indique honnêtement au lieu d'enregistrer un message qui n'existerait pas.
